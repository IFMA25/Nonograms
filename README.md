# Nonograms

Японские кроссворды (нонограммы) — игра на чистом JavaScript + Canvas, без сборщиков и зависимостей.

**Демо:** https://ifma25.github.io/Nonograms/

## Возможности

- 15 картинок: три уровня сложности (5×5, 10×10, 15×15)
- Случайная игра, показ решения, сброс
- Сохранение и продолжение последней игры (localStorage)
- Таймер и таблица результатов
- Звуковое сопровождение (можно выключить)
- Тёмная тема
- Адаптивная вёрстка

## Как играть

- **Левый клик** — закрасить / снять закраску клетки
- **Правый клик** — поставить / снять крестик

## Локальный запуск

Специальной сборки не требуется — достаточно открыть `index.html` в браузере
или поднять любой статический сервер, например:

```bash
npx serve .
```
